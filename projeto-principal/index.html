Fundamentos do HTML 5

O HTML5 - Hyper Text Markup Language - é a linguagem de marcação padrão para criar páginas web. Pensem nele omo a estrutura ou o esqueleto de qualquer site que vocês visitam

A versão 5 é a atual no mercado, e trouxe algumas novidades:

  • Recursos de APIs como armazenamento local (local storage), geolocalização, arrastar e soltar e web workers para processamento em segundo plano
  • Melhor suporte nativo para multimidia como imagem, vídeo e áudio
